5. Механизм Live-синхронизации между окнами (без перезагрузки)

sequenceDiagram autonumber participant T as Кабинет Арендатора (/tenant) participant DB as SQLite (mall.db) participant L as Кабинет Арендодателя (/) T->>T: Выбирает файл платежки (черновик в памяти) T->>DB: Нажимает «Отправить платежку в УК» -> attach_payment_receipt() DB-->>T: Статус формы: under_review loop Каждые 2.0 сек (ui.timer) L->>DB: db.get_sync_signature() DB-->>L: Кортеж из 9 агрегатов таблиц end L->>L: current_sig != last_sig -> ui.notify() + обновление UI и SVG-карты
